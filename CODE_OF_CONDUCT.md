# Code of Conduct

DupeLens is maintained by its author only. The repository does not accept
issues, pull requests, discussions or other contributions, so it has no
community spaces to moderate and no reporting channel.

The project keeps these standards in its code, documentation and history:

- **Neutral, respectful language** in all texts and commit messages.
- **No personal data of other people.** The repository contains no real
  photographs; examples and tests use synthetic images drawn by a script.
- **Original work.** Algorithms are implemented from their mathematical
  description; code from other projects is not copied.
