DupeLens

Duplicate photo finder that runs in your browser

Drop photos or folders here

or choose them — DupeLens finds exact copies and near-duplicates and asks you which ones to keep.

  • In your browser. Photos are read with the browser's File API and analysed in this page. The page declares a Content-Security-Policy that tells the browser to block network connections.
  • Transparent. Pixel analysis, no machine learning, no cloud. One documented similarity score.
  • You decide. DupeLens itself does not write to your files. You get a list and an optional script that moves files into a review folder.
